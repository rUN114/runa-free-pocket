# 周免口袋 0.2.0

Android 上的 Epic 电脑游戏、安卓游戏和 Fab 限时免费内容工具。本版重做了图片卡片、详情预览、账号授权和拥有状态同步。

**已完成构建、逻辑测试和浏览器界面验证，尚未在安卓真机上完成真实账号授权、库存同步和实际领取验收。** 界面预览中的拥有状态是明确标出的测试样例，不代表用户真实库存。

## 安装与使用

1. 安装随附的 `周免口袋-0.2.0-测试版.apk`。本版与 0.1.0 的包名和签名一致、版本号更高，可覆盖安装。旧安装包保留在交付目录。
2. 打开后会自动读取电脑游戏活动。进入“连接账号”，先确认 Epic 账号地区。
3. 点击“连接 Epic”，在 Epic 官方页面完成登录、验证码或授权。程序取得有效授权后会自动返回，读取完整拥有凭证，并同步当前列表。
4. 浏览手机游戏或 Fab 素材分类。Fab 需要在“账号与同步”中单独连接；已有网页登录状态时，官方可能直接完成连接。
5. 点击卡片图片可看简介和预览图。可隐藏已拥有、全选或勾选部分项目，再点击“领取所选”。
6. 领取前会重新同步拥有状态，队列跳过已拥有内容。验证码、年龄确认和许可协议由用户在官方页面处理；完成订单后重新核实拥有状态，未确认的结果不会当作领取成功。

网页遇到验证或读取失败时，程序会保留官方页面，显示具体提示。完成验证后可点“重试读取”或“重试连接”。“返回列表”停止当前流程；从手动商品页返回会自动同步当前分类。

最低 Android 8.0，并需要支持安全网页消息、页面启动脚本的 Android System WebView。系统组件过旧时，程序会提示更新。本版需要前台运行。

## 本次修改

- 使用大幅官方封面，叠加名称、原价、剩余时间、平台和拥有状态；拥有状态与选择框分别展示。
- 增加详情弹窗和可横向滑动的官方预览图。
- 使用经过 HTTP 验证的 Epic 图片缩放参数。一个样例封面从约 3 MB 缩小到约 40 KB；保留带签名的图片地址及其他提供方的原地址。
- Epic 账号授权与库存同步接入原生代码。会话使用 Android Keystore 的 AES-GCM 加密保存，不保存账号密码。
- 完整分页读取有效拥有凭证，按命名空间与库存商品 ID 匹配。报价 ID 不再误当库存 ID；电脑和安卓版本分开，组合商品识别全部或部分拥有。
- Fab 一次完整读取已获取素材库并批量更新状态，不再为每张卡片重复遍历同一素材库。
- 启动、连接完成、活动刷新及领取后自动同步。缓存拥有状态标明“缓存”和同步时间；请求失败不会变成“未拥有”。
- 只自动提交明确合计为零的订单；页面付款成功提示或点击下单，都不能单独代替拥有状态核实。

小黑盒仅用于理解信息布局和客户端分层。本工程没有复制它的品牌图、H5 业务脚本、私有后台接口或账号体系，也没有将用户账号发送给小黑盒。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 已拥有 | 当前账号拥有凭证、官方商品页或 Fab 已获取素材库已确认 |
| 已拥有 · 缓存 | 上次同步确认拥有，当前还未完成新一轮同步；时间会显示在卡片中 |
| 未拥有 | 完整同步结果未包含对应商品 |
| 部分已拥有 | 组合商品中的部分库存项目已拥有，尚未全部拥有 |
| 未能确认 | 尚未连接、尚未同步，或缺少可匹配的商品资料 |
| 同步失败 | 请求、授权或数据解析失败，不能据此认定未拥有 |

新版本会重读 0.1.0 的活动缓存，因为旧缓存没有保留封面和准确库存商品 ID。网页登录 Cookie 不会因此被清除；库存授权仍需在新版中连接一次。

## 开发与复查

- `MainActivity.java`：安卓界面、官方浏览器、任务队列、来源校验、同步及取消流程。
- `EpicSession.java`：授权交换、会话刷新、Keystore 加密和拥有凭证读取。
- `EpicEntitlements.java`：可单独测试的分页完整性规则。
- `EpicPublicApi.java`：公开促销数据请求。
- `assets/domain.js`：活动与图片资料解析、库存商品匹配、金额判断和选择规则。
- `assets/automation.js`：官方网页登录回调、Fab 素材库和网页领取处理。
- `assets/ui.js / style.css / index.html`：手机卡片与详情界面。

JDK 17+、Android SDK Platform 35、Build Tools 36；工程附有 Gradle 9.3.0 Wrapper。生产依赖仍只有已有的 AndroidX WebKit 及其传递依赖，没有增加新的生产依赖。

```powershell
# 工程目录执行。local.properties 配置你自己的 SDK 路径，如 sdk.dir=D\:/Android/sdk
./gradlew.bat assembleDebug lintDebug
./tests/run-tests.ps1
```

测试不包含真实账号或自动下单。界面验证使用本地示例库存和公开活动资料；截图中明确标明了这一点。
