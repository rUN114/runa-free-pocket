# 1.0.1 网络与 Fab 许可测试候选

2026-10-30。本版用于手机回归验证，尚未作为正式 GitHub Release 发布。可覆盖安装 1.0.0 正式签名包，保留本机数据；0.x 调试签名不兼容。

## 修改

- WebView 主页面失败显示阶段、域名与错误码，不再把所有错误归为网络故障；不输出授权网址查询参数。
- 页面加载超过45秒显示提醒。仅登录、活动读取和 Fab 库存同步的连接/超时错误自动重试一次；订单提交不自动重试。
- 页面工具栏增加网络诊断：对官方域名进行不携带账号 Cookie 的系统 HTTPS HEAD 探测，显示状态码或异常类型。系统探测不等于内置网页登录成功。
- 设置增加 Personal / Professional 明确选择，不根据账号或昵称推断收入。
- 依据当前官网 #license-select 控件和 role=option 选择请求档位，核对该选项本身的 Free -100% 标记。原生 SELECT 只读取选中的 option。
- 商品页许可检查与本次任务绑定，原生持久化后才允许打开购买；后续结算要求本次许可确认及明确零元合计。许可改变或离开关联流程时确认失效，不跨任务、恢复任务或商品复用。
- 记录区分请求档位和商品页确认档位；素材库存按商品判断，显示已拥有不代表已独立核实该档位授权。暂不支持据此补领第二档许可。

## 验证与限制

- 78项 JavaScript 测试通过，覆盖档位缺失/不匹配、许可改变、无确认直达结算、所选档位付费、原生SELECT双选项，以及原有零元限制和一次提交规则。
- 现有30项 JUnit、Release构建与Lint通过；Lint仍有警告，未禁用规则。浏览器在320/360/390/480宽度检查交互及许可设置布局。
- 独立 Android 12 模拟器中覆盖安装并启动成功，签名与1.0.0一致。
- 实际非调试包通过 networkErrorInspect：官方域名的不可用端口触发WebView错误，原生状态提示包含域名且不泄露测试查询参数。此项是故障注入，不代表用户网络或首次登录已通过。
- 实际官网商品页控件结构已查看。fabCheckoutInspect仅尝试打开结算、不提交订单，因许可选项未出现而中止，没有取得新的结算或新增入库实证。
- 许可证明仅指本次商品页所选档位已核对，不是独立的订单许可审计。未知商品页结构或不明确的零元合计仍暂停。
- 用户手机的 ERR_CONNECTION_ABORTED 根因尚未定位；测试包不能保证解决所有跨境连接问题。未新增代理服务器、未绕过验证码、未通过降低TLS校验处理连接问题。

## 手机复查

1. 覆盖安装测试APK，先在账号与同步中选择适用的Fab许可档位。
2. 尝试Fab连接；失败时记录阶段、域名和错误码，可运行网络诊断并在两种网络下对照。
3. 本期内容已拥有时只核实库存；未拥有时检查所选档位与零元订单。待核实项目先同步，不重复自动提交。
4. 出现回归时保留记录与截图，停止领取。旧APK versionCode较低，不能保证直接覆盖回退；不要为回退随意卸载或清除应用数据。

源码与测试保存在独立恢复的Git目录 outputs/runa-free-pocket-repair。原目录仅残留构建缓存，未删除或覆盖。
