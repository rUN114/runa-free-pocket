# 小体积原生化设计

用户已批准“原生界面＋结构重构，优先小体积”。这是已有产品的原生迁移，保留品牌、内容和操作模型，不重新命名或重做品牌。

## 行为与范围

- 电脑/手机/Fab分类、活动列表、即将推出、封面/截图详情、拥有状态、选择领取、一键全部、账号设置与切换/退出、许可档位、地区、领取历史与恢复均改为 Android 原生视图。
- 本地目录界面不再使用 WebView/HTML。WebView仅用于官方认证、抓取必须处于官方会话的数据、验证码和结算；交互自动化 JavaScript 是网站适配层，不能凭“原生”名义删除。
- AndroidX RecyclerView负责列表复用；Activity/Lifecycle ViewModel负责屏幕状态和生命周期；Coroutines负责异步边界。已有HTTP、图片缓存和KeyStore实现沿用，不引入Compose、Room、Hilt、通用网络框架或字体包。
- 业务分层：原生UI与ViewModel、领取协调器、目录/设置持久化、纯Kotlin规则、官方网页控制器。Activity不再承担队列和持久化。
- 原生层使用明确的数据模型及动作；JSON仅留在外部接口、网页消息和兼容的账本/缓存格式边界。领取账本、账号加密别名与preferences键保持兼容。
- 旧版本工作区和桌面副本保持不变；在独立 Git 工作区开发，完成后提供新APK及新版源码。

## 界面

保留深蓝月夜、奶油白文字、月光金主操作及既有像素插画。使用原生顶部栏、三个分类切换、清晰的主领取动作、真实封面列表及原生详情/账号/记录视图。收紧过大的装饰区，优先让首屏出现状态和商品。保留用户熟悉的分类及动作，不重新发明导航。

最小48dp触摸目标、sp字体、系统Insets、可访问标签、原生返回。手机单列，宽屏适当增加列数；1.3倍字体不裁切重要状态和按钮。显示错误、空数据、加载、离线/缓存与拥有未知，不以默认空列表掩盖失败。

## 验收

1. 主目录没有WebView；原生界面覆盖现有常用交互，预告不可选、已拥有不可重复领取。
2. 现有53项JVM和网页适配脚本回归继续通过，迁移的新规则、账号切换、保存失败与队列恢复补真实风险用例。
3. 原生UI在真实模拟器上检查手机/宽屏、字体1.3倍、暗色和主要错误状态；本机UI样例不得冒充真实账号结果。
4. 读取旧缓存、账本、保护预约与加密会话；旧不确定订单仍只核实。
5. 正式APK使用原签名、R8与资源压缩，记录大小。优先争取1MiB以内；超出先定位依赖/资源，不削功能凑体积。
6. 无可用未领取项目时明确新的真实订单尚未验证，不清保护或换假数据制造成功。
