# 2026-10-31 真实账号验证

本次由用户在隔离的 Android 模拟器中手动完成官方登录及商品页安全检查，未向聊天提供密码。测试使用压缩、非调试的 1.0.1 候选构建；模拟器覆盖安装使用测试签名，分发 APK 使用原发布签名，代码与资源一致。

## 发现与修复

- 原商店 WebView 使用默认的 JavaScript 窗口设置。真实页面已取得结算会话，但结算未显示；仅在诊断中启用自动窗口后，出现了官方 `https://store.epicgames.com/checkout` 子帧。修复仅作用于商店 WebView，不改变本地目录页面的设置。
- 原消息规则拒绝该同源结算子帧的提交消息。现在自有脚本附带无查询参数的页面路径，对 `/checkout` 增加路由支持，同时保留 WebView 提供的来源、主/子帧身份、任务类别、nonce、账号绑定及持久化一次性许可。脚本声明的路径不作为独立的安全证明。
- 领取入口操作后显示等待结算及验证的提示，不再继续停留在“等待商品主按钮”的旧消息，也不将打开入口当作下单或已拥有。

此前为定位问题执行过只打开领取入口的诊断，没有点击最终提交按钮；这些诊断不计为自动领取成功。完整诊断原件、账号标识和截图保存在本机私密目录，不纳入源码或 Git。
